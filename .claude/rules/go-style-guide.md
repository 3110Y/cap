# Rule: go-style-guide

## Общие положения

- Следуйте [Effective Go](https://go.dev/doc/effective_go) и [Go Code Review Comments](https://github.com/golang/go/wiki/CodeReviewComments).
- Используйте `gofmt` и `goimports`.
- Имена пакетов — короткие, строчными буквами, без подчёркиваний.
- Экспортируемые идентификаторы начинаются с заглавной буквы.

## Структура проекта

- `cmd/` — точки входа.
- `internal/` — код, не предназначенный для внешнего использования.
- `pkg/` — библиотеки, которые можно импортировать другим проектам (если есть).

## Обработка ошибок

- Не игнорируйте ошибки. Используйте `if err != nil { return err }`.
- Оборачивайте ошибки с контекстом: `fmt.Errorf("failed to clone repo: %w", err)`.

## Комментарии

- Каждый экспортируемый тип, функция, метод должны иметь комментарий, начинающийся с имени.
- Комментарии на английском языке.

## Тестирование

- Тесты размещайте в файлах `*_test.go` рядом с тестируемым кодом.
- Используйте `testify/assert` или `testify/require`.
