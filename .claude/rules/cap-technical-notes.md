# Rule: cap-technical-notes

## ID репозитория

- Случайная строка: первые 8 символов SHA-1 от `URL + соль`.
- Генерируется при `cap repository add`.

## Поиск установленных примитивов

- Рекурсивный обход всех поддиректорий `.claude` от текущей рабочей директории.
- Активной считается последняя установленная версия (или явно выбранная пользователем).

## Версионирование

- Все версии должны соответствовать спецификации [SemVer](https://semver.org).

## Синхронизация кеша (`cap update`)

1. Удалить поддиректории в `~/.cache/cap/repos/`, чьи `id` отсутствуют в `repositories.yml`.
2. Для оставшихся репозиториев — синхронизация с удалённым источником (`git clone` или `git fetch --prune`).
3. Все `index.json` из клонов объединяются в `~/.cache/cap/indexes.json`.

## `indexes.json` как единый источник правды

- Используется для всех операций маркетплейса (`marketplace list/search/info`).
- Не читается напрямую из клонов — только из `indexes.json`.

## Конфликт версий

- При установке существующий примитив перезаписывается (или обновляется до указанной версии).

## Регулярные выражения

- Синтаксис Go (совместимый с RE2).
- По умолчанию поиск **регистронезависимый**.

## Пространства имён Claude

- После установки примитив доступен Claude через `cap:<vendor>:<name>`.
- Пользователь вызывает примитив в диалоге по этому имени.

## Валидность репозитория

- Отсутствие `index.json` в корне репозитория делает его невалидным.
- При синхронизации такой репозиторий пропускается с предупреждением.
