# Command: dev-helper

## Описание

Добавляет в окружение разработчика набор сокращённых команд для ускорения работы.

## Команды

| Команда     | Действие                                     |
|-------------|----------------------------------------------|
| `dev test`  | Запуск всех тестов с флагом `-race`.         |
| `dev lint`  | Запуск `golangci-lint`.                      |
| `dev gen`   | Вызов `go generate ./...` (включая Wire).    |
| `dev build` | Сборка бинарного файла.                      |
| `dev clean` | Очистка кеша сборки.                         |

## Пример использования

```bash
dev-helper test
```
