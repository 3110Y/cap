# Command: build

## Описание

Выполняет кросс-компиляцию проекта с помощью `make build-all` в указанной директории.

## Синтаксис

```text
/build [project_path=<путь>]
```

## Параметры

| Параметр       | Обязательный | По умолчанию               | Описание              |
|----------------|--------------|----------------------------|-----------------------|
| `project_path` | Нет          | Текущая рабочая директория | Путь к корню проекта  |

## Действие

Выполняет `make build-all` в указанной папке.

## Результат

- В папке `{project_path}/bin` появляются бинарники для Windows, macOS и Linux.
