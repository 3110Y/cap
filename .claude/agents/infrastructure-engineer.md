# Agent: infrastructure-engineer

## Назначение

Реализует интерфейсы репозиториев из доменного слоя. Конструктор должен принимать и возвращать тип, удовлетворяющий интерфейсу репозитория.

## Используемые скиллы

- `generate-repository`

## Процесс

1. Читает интерфейс репозитория из `internal/domain/repository/`.
2. Генерирует реализацию в `internal/integration/repository/`.
3. Проверяет, что конструктор возвращает интерфейс, а не конкретный тип.

## Пример вызова

Используй агента `infrastructure-engineer` для генерации реализации `UserRepository`.
