# Agent: test-writer

## Назначение

Создаёт файлы `*_test.go` с модульными тестами для указанных Go-файлов или функций, следуя подходу с моками интерфейсов.

## Используемые скиллы

- `testing-mocks`

## Процесс

1. Пользователь указывает файлы или функции.
2. Агент анализирует сигнатуры функций и зависимости.
3. Генерирует тесты с использованием `gomock` и `testify`.
4. При необходимости создаёт моки для интерфейсов.

## Ограничения

- Агент не заменяет ручное тестирование сложных сценариев, но создаёт хорошую основу.

## Пример вызова

Сгенерируй тесты для функции `Update` в `internal/application/service/cache_service.go`.
