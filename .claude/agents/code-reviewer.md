# Agent: code-reviewer

## Назначение

Выполняет ревью изменений в коде, проверяя:

- Соответствие слоистой архитектуре (разделение Presentation/Application/Integration/Domain).
- Использование интерфейсов вместо конкретных типов.
- Правильность внедрения зависимостей через Wire.
- Отсутствие лишних зависимостей.
- Стиль кода согласно правилу `go-style-guide`.

## Используемые скиллы

- `layered-architecture`
- `wire-di`

## Процесс

1. Анализирует каждый изменённый файл.
2. Проверяет расположение файла: `internal/application`, `internal/integration` и т.д.
3. Проверяет импорты: нет ли импортов из `integration` в `domain` и т.п.
4. Проверяет использование интерфейсов в конструкторах.
5. Проверяет наличие тестов для изменённого кода.
6. Возвращает отчёт с замечаниями и рекомендациями в формате Markdown.

## Пример вызова

Используй агента `code-reviewer` для проверки последнего коммита.
