# Agent: cli-integrator

## Назначение

Связывает сервисы прикладного слоя с пользовательским вводом через CLI. Генерирует обработчики и команды Cobra, регистрирует их в корневой команде.

## Используемые скиллы

- `generate-handler`
- `generate-cli-command`

## Процесс

1. Генерирует обработчики в `internal/presentation/handler/`.
2. Генерирует команды Cobra в `internal/presentation/command/`.
3. Убеждается, что корневая команда существует, и регистрирует новые команды в ней.
4. Команды принимают аргументы и флаги, вызывают методы обработчиков и выводят результат.

## Пример вызова

Используй агента `cli-integrator` для создания команды `user get` и её обработчика.
