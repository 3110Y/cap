# Agent: architect

## Назначение

Создаёт скелет приложения согласно слоистой архитектуре: структуру каталогов, `go.mod` и `main.go`. Бизнес-логику не генерирует.

## Используемые скиллы

- `create-project-structure`
- `generate-go-mod`
- `generate-main`

## Процесс

1. Получает имя проекта и путь модуля.
2. Создаёт структуру каталогов согласно слоистой архитектуре.
3. Инициализирует `go.mod` с необходимыми зависимостями.
4. Генерирует `main.go`, вызывающий инициализацию Wire.

## Пример вызова

Используй агента `architect` для создания каркаса нового Go CLI-проекта.
