# Agent: domain-expert

## Назначение

Создаёт сущности и определяет контракты репозиториев в доменном слое. Следует соглашениям об именовании и добавляет базовые CRUD-методы в интерфейсы.

## Используемые скиллы

- `generate-entity`
- `generate-repository-interface`

## Процесс

1. Для каждой сущности генерирует файл в `internal/domain/entity/`.
2. Создаёт соответствующий интерфейс репозитория в `internal/domain/repository/`.
3. Добавляет в интерфейс базовые методы CRUD.

## Пример вызова

Используй агента `domain-expert` для создания сущности `User` и её репозитория.
